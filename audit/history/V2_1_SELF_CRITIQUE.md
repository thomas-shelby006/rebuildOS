# v2.1 Self-Critique

## Verdict
v2.1 is a routing and usability consolidation release. It improves whether the right protocol fires at the right time.

## Strong
- Timesheet now appears in the two most important daily anchor templates.
- Shame bank is routed explicitly, reducing inconsistent shame responses.
- Transition Mode is defined before it is urgently needed.
- Write-off week prevents weekly review from becoming a shame audit.

## Watch points
- The system remains large. File-loading priority must be respected.
- Transition Mode should not be used prematurely; only activate when resignation/notice/new-job context exists.
- Weekly one honest question should stay one question, not become a long reflection exercise.
- Timesheet anchor should not turn into long timesheet administration; one line is enough.

## Next likely improvement after real use
Do not add features immediately. Run for several days and inspect where Sundar actually skips interaction.
